# Synthetic Raw Data — Provenance

These files are synthetic participant-level clinical-trial data created for an educational portfolio project.

Clinical foundation:
- ClinicalTrials.gov study NCT02537470.
- The public study design is used only as a conceptual clinical foundation.

Important:
- These records are NOT actual participant data from NCT02537470.
- No real patient-level data were used.
- The three treatment arms and participant-level values are part of the synthetic educational design.
- The data were generated with a fixed random seed so the dataset can be reproduced.
- This is the clean synthetic raw/EDC-like stage. Deliberate data-quality errors have not yet been introduced.
